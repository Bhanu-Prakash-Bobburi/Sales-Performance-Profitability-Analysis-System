Built an end-to-end Power BI analytics solution using sales transaction data to monitor revenue, profitability, product performance, and customer behavior. Developed interactive dashboards with dynamic KPIs, YoY analysis, customer segmentation, profit analysis, and executive reporting using DAX, Power Query, data modeling, and advanced visualizations.
